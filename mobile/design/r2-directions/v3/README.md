# v3: from the reference apps' real screens

After Arqila called v2 "AI slop" (gradient blobs, glass, emoji, heavy type, purple off-brand). Built from what the
real GoPay, Grab, myBCA and Todoist screens do, not from their store banners:

- **Edunex blue in one header area**, holding the class on now and its one button (as GoPay holds the balance), with
  a faint diagonal texture. The content sits on a grey sheet that overlaps it with rounded corners (GoPay, myBCA).
- **White grouped sections with hairline dividers, no shadows.** Section titles 17 sp semibold, rows 16 sp medium,
  meta 14 sp regular grey. Roboto, the phone's own font, at medium weights (no black weights).
- **Course icons on white tiles with a hairline** (GoPay's and Grab's service tiles), each course its colour.
- **Status as an outlined chip** (Grab's "Diskon 70%"), one per row.
- **Jadwal and the class sheet calm as Todoist**: a day timeline with muted course tints and a coloured edge, red only
  for today and now; the sheet as Todoist's task sheet (a breadcrumb, the title, three facts with icons, one blue
  button, one outlined).

Words above the tab bar: Beranda 45, Jadwal 42, class sheet 23. Joy comes from motion and haptics in the build, not
from decoration: press springs, Tandai Hadir's check drawing itself, the now-line moving, rows staggering in.
