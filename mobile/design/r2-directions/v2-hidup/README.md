# v2 · Hidup

After Arqila's "why is it so plain?": the same text budget (Beranda 47, Jadwal 37, class sheet 21 words), with the
personality the first three directions lacked. Each course has its own colour and an icon tile (Ekonomi a chart,
Komunikasi a megaphone, Infrastruktur a train, Penyelesaian Masalah a puzzle piece, Tugas Akhir a cap). The class on
now is a vivid card in its course's colour with a live progress bar and one white button. Big numbers for what needs
you. Type: Plus Jakarta Sans for headings and numbers (OFL; designed for Jakarta's city identity), Roboto for text.
`build.mjs` renders these (fonts and icons from /tmp in the lead's session).
