Get started

Three steps, about two minutes.

Free for every ITB student, on macOS, Windows and Linux.

Mac

  1. 1

    Download the file for your Mac

    Open it, then drag Edunex Plus into Applications.

    Apple silicon (M1 or newer) Intel

    Not sure which? Apple menu, then About This Mac.

    Edunex Plus
    Edunex Plus Applications >_Terminal
  2. 2

    Open it

    The app isn't signed yet, so macOS blocks it the first time. In the same window, open Terminal, paste this line and press Return. Then open Edunex Plus from Applications.

    Rather not use Terminal?

    Open the app once and click Done. Then go to System Settings → Privacy & Security and click Open Anyway.

    Terminal
    % xattr -cr "/Applications/Edunex Plus.app"

Windows

  1. 1

    Download the installer

    For Windows 10 or 11. If your browser holds it back, choose Keep.

    Intel or AMD (most PCs) ARM (Snapdragon)
  2. 2

    Open it

    The app isn't signed yet, so Windows warns you the first time. Click More info, then Run anyway. It installs and opens by itself.

    1 Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk. More info Don't run
    2 Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk. App: Edunex-Plus-Setup-….exe
    Publisher: Unknown publisher     Run anywayDon't run

Linux

  1. 1

    Download the file for your system

    The .deb for Ubuntu, Debian and Mint, or the AppImage for other Linux.

    Ubuntu, Debian, Mint Other Linux
  2. 2

    Install it

    In the folder you downloaded to, run this line. Then open Edunex Plus from your apps menu.

    Terminal
    $ sudo apt install ./edunex-plus_<version>_amd64.deb

Privacy

Your data stays on your computer.

  • Your password never reaches the app. Only Microsoft sees it.
  • Locked in your keychain. What it reads is saved only on this computer.
  • No analytics, no tracking. "Sign out & remove data" in Settings deletes everything it saved.
